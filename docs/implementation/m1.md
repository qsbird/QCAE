# M1：文档、组织与受控格式切片

本切片在 M0 的同一本地 engine 中扩展文档模型，提供受控文本资源的导入预览、原子提交、组织编辑、引用查询和导出预览。仍是内存工作文档，退出进程会丢失模型和历史；不是完整 M1/P0 验收。

## 数据与事务

公共模型包含节点、两节点梁、线弹性材料、梁截面、节点力、节点约束、分析定义，以及独立的部件、装配、集合、INCLUDE 关系。公共工程单位为 mm、N、MPa。卡片名/字段布局留在适配器，核心没有 Qt、Nastran 卡片类或存储库类型。

- 所有实体以 EntityId 引用；来源编号按来源模型及编号空间区分，导出编号单独冻结在 ArtifactPlan 中。
- 部件可共享节点，梁单元只有一个部件归属；装配为单父层级，禁止循环；集合保存同类节点或梁的成员快照。
- INCLUDE 独立维护路径、父包含关系和实体归属，不用 INCLUDE 自动伪造部件。内部引用跨 INCLUDE 仍指向相同 EntityId。
- 提交前检查重复身份、类型错误/悬空引用、循环、数值有效性和数量配额。删除被引用对象会拒绝，不做隐式级联删除。
- 导入只允许空模型；文本先解码成候选模型，再调用同一应用服务生成预览。提交仍检查 actor、文档、epoch、revision、preview 和幂等键。
- 组织修改、节点移动和材料修改共用提交及历史。Undo/redo 恢复整个模型与来源关系，并生成新 revision；当前使用有数量上限的完整快照，M2 才实现差量持久历史。

反向引用及影响分析从冻结模型推导。当前分析使用整份梁网格，材料/截面/梁/几何变化保守地影响使用该网格的全部分析；未被物理对象引用的组织关系变化不改变力学输入。尚未开放以集合驱动载荷的编辑命令。

## 运行入口

继续使用 [M0 构建命令](m0.md)。`QCAE_BUILD_IPC=OFF` 也会编译纯 C++ 格式适配器和领域测试，不需要额外库。开启 IPC 时宿主静态注册 Nastran codec，并通过通用接口注入适配层；核心不链接具体 codec。

完整协议用例见 `tests/m1_ipc_tests.py`；输入夹具位于 `tests/fixtures/nastran/`。操作目录仍使用 API 1.1，新增可发现的 `model.export_preview` 查询，不改变既有写入契约。

| 操作/命令 | 本轮语义 |
|---|---|
| `capabilities.list` | 声明包及不可变 ProfileRef；codec 可用，求解器 configured/validated 仍为 false |
| `changes.preview` / `model.import` | parameters 提供 root_resource、resources（path/text）、source_profile_ref、unit_system；返回预览及 ImportReport |
| `changes.commit` | 使用上一步 preview_id，在相同预期修订提交；导入作为一个可撤销事务 |
| `changes.preview` / `part.upsert` | 名称及 members；无 entity_id 时创建，有 ID 时更新已有部件 |
| `changes.preview` / `assembly.upsert` | 名称及 children；子项为部件或装配 |
| `changes.preview` / `set.upsert` | 名称及同类节点/梁 members |
| `changes.preview` / `node.move` | entity_id 及 position_mm 三分量数组 |
| `changes.preview` / `entity.delete` | 删除实体；存在引用时返回诊断 |
| `entity.query` | kind、name_contains、ids 的交集；view/owner_id 组织视角；offset/limit 分页 |
| `entity.references` | entity_id、direction=incoming/outgoing；返回直接关系及 affected_analyses |
| `model.export_preview` | analysis_id、expected_profile_ref，加请求层 expected_revision；返回文本资源、冻结编号映射、版本和 ExportReport，published=false |

query 的 view 可为 all、part、assembly、set、include、material、property。装配视角展开所属层级；部件/装配视角包含梁的连接节点，使用 kind 可限制最终实体类型。集合只返回保存的成员，INCLUDE只返回包含树内归属的实体，不沿物理引用跨文件扩展。材料视角展开截面→梁→节点，属性视角展开梁→节点。查询结果携带 revision，但尚不是 M3 的 SelectionHandle；复杂布尔条件、空间/可见性查询也留在 M3。

`model.import` 和 `model.export` 两个后台作业操作本轮仍标记 planned。导入预览命令和导出预览查询是同步、有体量限制的 M1 入口，不伪装成已实现任务状态机或文件发布。客户端目前提交文本资源包，服务端不从请求中任意读取文件路径。

## 格式与能力边界

详见 [受控 Nastran 子集](nastran-subset.md)。采用官方 MSC 文档核对的基本 SOL 101 梁语义，显式要求 mm-N-MPa；不猜测输入单位。首版只接受受限自由格式，数值字段最多8字符；无法精确表示的导出数值返回阻塞诊断，大字段/续行另行扩展。构建时对适配器、领域验证、相关声明和支持矩阵生成 SHA-256 定义摘要；改动相关语义后旧 ProfileRef 会不匹配，不自动重解释。

ImportReport/ExportReport 带文件、行号及阻塞/非阻塞诊断。未知卡片、语法或无法表达的物理字段拒绝导入/导出；部件/装配/集合等 BDF 不能表达的平台信息通过损失报告提示。文本布局、注释与平台名称不保证原样往返。

导出只生成内存 ArtifactPlan，不写外部文件，没有声明多文件原子发布。需要的临时目录、清单、文件发布幂等及长任务在后续切片实现。

## 配额与实际验证

核心默认实体总数上限 100000、材料 10000、引用关系 500000、历史/预览各 128、幂等记录 4096。限制按数量计，不是 RAM 硬配额或容量性能承诺。IPC 仍受 M0 的 1 MiB 帧限制；较大输出明确返回 RESOURCE_LIMIT，分页查询可限制返回量。

本轮最终验证：Release 8/8、ASan/UBSan 8/8、本地Qt Debug 10/10 CTest通过。独立审查发现已修复，详情登记在 [验证记录](../baseline/validation-record.md)。测试范围包括整体模型撤销、引用与组织约束、格式语义往返、拒绝未知/异常输入，以及真实 CLI/engine 集成。没有真实求解器、Windows、GUI、性能或 AI 端到端的完成证据。

ENV-02 的文档语义与本 codec 版本已确定；本机求解器方言/二进制版本兼容性仍未验证。实际求解器接入前必须核对支持矩阵和数值夹具。
