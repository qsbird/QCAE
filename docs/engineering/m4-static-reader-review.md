# M4 受控静力结果解析审查

2026-10-01，QG-02/QG-03。范围为 Nastran profile 的纯 C++ F06 解析 DTO；
生产 solver/result 发布链尚未完成，当前事实不授予 external_solver 来源或数值通过。

入口 `read_nastran_static_f06` 接收受限文本、显式 subcase/单位/基本坐标与运行
冻结的 GRID→稳定 ID 映射。先验证上下文和映射，再逐行识别当前工况及结果表，
最后要求完整位移及至少一个 SPC 反力。输出保留平移/转角、力/力矩六分量及其
各自单位；不使用当前模型编号补映射，不访问 UI、文件、进程或数据库。

状态不变量：只有独立 SUBCASE 元数据可建立结果工况；分页清除当前表和工况，
作业结束后不能建立新结果表。未知标题离开当前表，后续 MPC 不能继承 SPC。
ASA 0 仅在已识别元数据上移除；数值行必须有已识别表、完整列、正整数冻结 GRID
及六个有限分量。过长/NUL/fatal、重复或未知编号、错工况/单位/坐标均拒绝。
这些规则是受控 reader 的支持范围，真实版本的分页/打印控制仍需实际 F06 验证。

独立复核发现首版错误后保留原失败日志；7 个误成功因果输入均已拒绝，另 16 个
ASA/分页/行边界符合预期。root 新 Release 编译及同测试 CTest 1/1 通过（0.46秒），
包含修正版预登记四文件经生产 codec 导入且无 issues。证据见
[m4-numerical-preregistration.md](m4-numerical-preregistration.md)；未知 MPC 表、空
SPC 后 MPC、带符号非法行、echo 来源和 END 后结果为显式负例。

当前无需适配器或额外库：解析返回不可变值，无提交、副作用或状态认证。
解析成功不表示工程验证成功；生产发布将另行绑定可信执行、输出 manifest、
冻结输入/配置/映射、reader 版本与逐分量数值核验。真实执行及该发布集成未执行。
