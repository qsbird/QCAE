# P0 AI 验收用例 v0.6

> 历史讨论：本文件保留当时的分析与估算；当前开发依据为 [设计基线1.0](baseline/README.md)。冲突时不沿用本文件旧范围。

状态：测试设计，尚未执行。用户已选择外部 AI 客户端，软件保留 GUI；所有用例调用共用业务服务。

## 基准与证据

基准为一维、等截面、线弹性、小变形静力悬臂梁，固定一端、另一端指定坐标方向的集中力。材料、截面、单位、Nastran 方言和真实求解器需在执行前固定。位移及反力/力矩的参考值、适用理论、允许误差在首次候选运行前登记，不根据运行结果反向调整。

每次记录模型/分析输入版本、调用记录、求解器版本与输入、日志、结果和各项检查结论。模拟任务可以测试故障路径，但不能冒充真实求解通过。

## 十项关键测试

| ID | 输入/操作 | 期望与失败判据 |
|---|---|---|
| AI-01 单位 | 输入没有单位的长度、截面、E、力；随后补齐 mm/GPa/N | 初次返回 needs_input 且不提交可求解模型；补齐后归一化一致。默默假设 SI、导出与显示不一致均失败 |
| AI-02 物理歧义 | 输入“左端固定、右端向下受力”；旋转相机后重复 | 固定端身份与载荷坐标方向明确；信息不足则澄清。相机改变载荷方向、缺力值仍运行均失败 |
| AI-03 共享属性 | 20单元共享属性，选择10个要求“仅这些单元改变” | 预览报告20个引用者；使用受支持的复制/重分配操作，或明确不支持；不能把修改全部20个视为成功。一次撤销完整恢复 |
| AI-04 版本冲突 | AI基于V10预览修改，GUI先提交同一文档成为V11 | 提交返回conflict且V11数据不变；重新读取后才可建立新预览。静默覆盖用户值失败 |
| AI-05 重试 | 已提交但响应丢失；新request_id、同idempotency_key/参数重试；再同键改参数 | 重试返回原事务，只一个载荷/历史记录/修订；异参同键拒绝。重复创建或重复增加历史失败 |
| AI-06 取消/失败 | 计算阶段取消、提交前故障、提交后取消；求解中取消 | 未提交修改全部丢弃；已提交报告真实完成状态；求解取消保留输入，部分结果无效。半模型或误称已撤销失败 |
| AI-07 陈旧结果 | V20求解期间载荷修改为V21，V20结果随后返回 | 返回V20来源和非当前结果标识；不得用其回答V21载荷问题。仅按工程名关联或覆盖当前结论失败 |
| AI-08 求解与验证 | 真实运行正确基准；再运行偏离目标工况的可求解模型；注入退出成功但损坏结果 | 分离执行状态、解析状态、检查状态；正确基准满足预登记指标，错误工况和坏结果不能通过。模拟结果替代真实证据失败 |
| AI-09 恢复 | 已持久化V31，V32提交途中故障；保留状态未明任务后重启 | 恢复到声明持久化边界的一致状态，无半V32；任务中断/待核实/完成有依据。无证据宣称成功或重复运行不记录失败 |
| AI-10 人机一致 | AI建模、GUI改力、AI撤销、保存重开；再无窗口执行同一完整流程 | 同一历史撤销GUI修改；重开保留所存结果；无窗口可执行并获得结果。独立AI模型副本或依赖模拟点击失败 |

## 交付门槛

1. 支持的每项P0业务能力有至少一个不启动GUI的契约测试；界面装饰不计入业务覆盖。
2. 上述10项关键用例全部通过，模型语义、状态和证据判定不依赖AI措辞。
3. 确定性服务测试覆盖可重复故障注入；每项AI用例至少3次独立会话执行，记录模型和配置，关键错误为0。该小样本门槛不宣称普遍可靠性。
4. 至少一次外部真实AI客户端 + 真实Nastran求解器 + 完整结果核验。任何一项用替身代替都不能标记此条完成。
5. 缺少实际求解器或模型接入环境时，其他契约测试可以推进，但相关端到端验收明确为未完成。
6. 非图形测试在没有活动窗口时执行；离屏出图另测，不让图形环境失败阻断模型读写和求解。

## 测试边界

会话恢复不默认包含算法断点续算或跨重启无限撤销。资源上限按已选目标机器和明确配额验收。反力/位移参考值及容差需由选定梁模型的理论假设和数值方案确定，本计划不伪造尚未执行的数值结果。

本用例集吸收了独立只读审查的异常覆盖建议；接口定义仍以 [交付方案](P0-AI接口与悬臂梁交付方案-v0.6.md) 为准。
