## 参考研究正式吸收的三项设计

1. **OperationDescriptor**：一个操作定义承载参数、单位、前置条件、输出、错误和副作用。能力发现、MCP说明、CLI帮助及契约测试从它获取信息。
2. **ImportReport / ExportReport**：格式适配显式报告支持/遗漏/编号映射和语义损失。未知或无法保持正确的输入不能静默转换。
3. **ChangeImpact**：结合字段和引用关系判断模型、分析输入、检查和显示的失效范围。集合被载荷引用时，其成员变化也影响分析。

这些落在现有模块，不新增大型框架。Gmsh同步不是平台提交，脚本回放不是undo，SQLite事务不是外部文件原子发布，求解器退出成功不是结果核验通过。

架构已确定；以下是实施门禁，不能凭空填写为已通过：

- M0记录实际OS、编译器、Qt/VTK/SQLite兼容版本及IPC路径。
- M1锁定目标Nastran方言的受控卡片/语法支持矩阵。
- M2设置历史、内存、临时目录配额及恢复保留策略。
- M3定义中小模型分档、图形后端、硬件与响应性基准。
- M4配置真实Nastran可执行程序和数值验收夹具；没有求解器则该验收未完成。
- M5配置一个实际外部AI客户端及模型，记录数据去向和接入证据。

已登记的环境与运行证据见[C2验证](../engineering/c2-validation.md)；尚缺的真实求解器、AI及性能配置不阻止独立切片开发，也不能被模拟结果替代。
